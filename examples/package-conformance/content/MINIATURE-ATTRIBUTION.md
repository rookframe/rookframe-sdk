# Installed Miniature Fixture Assets

The Knight and armored Goblin models in this directory were supplied by the
repository owner for deterministic repository tests and showcase content. The
supplied downloads did not include license or attribution files, so this
repository does not assert or invent upstream license terms.

The Knight glTF keeps the supplied geometry, materials, and textures. Its
exported scene root was recentered and unrelated empty camera, armature, and
light roots were excluded from the default scene so it projects at the
authoritative Miniature pose.

These static Godot scenes are derived from Bevy commit 1230e73777ee0fa2f4e17ec8c804e0c4061465de using stock GLTFDocument and ResourceSaver. Textures are saved losslessly as PNG. The original Miniature scales are retained (Amber Warden 0.45; Goblin Raider 0.65).
